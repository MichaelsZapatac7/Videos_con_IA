# Biblioteca de música de fondo (MZSHARD)

Pistas instrumentales para usar en bucle bajo la narración (volumen ~20%).
Agrega más archivos .mp3/.wav aquí y el pipeline podrá seleccionarlos.

Uso en el pipeline:
- Por defecto se elige una pista automáticamente (rota entre las disponibles).
- Para forzar una:  --music "Architect_Studio"  (nombre sin extensión)
